## [0.1.0] - 2026-11-05

### Added
- Plugin manifest at `.claude-plugin/plugin.json`.
- `market-research` skill: TAM/SAM/SOM sizing, CAGR, scenarios, and market entry assessment.
- `competitor-intel` skill: competitor discovery, feature and pricing comparison, SWOT, and positioning.
- `opportunity-finder` skill: ranked opportunities with a weighted, explainable scoring model.
- `report-generator` skill: 18-section cited research report with confidence assessment.
- README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, and MIT license.
- GitHub Actions workflow validating the manifest and skill frontmatter.
- Issue and pull request templates.
