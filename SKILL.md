# Research Report Generator

Assemble a professional report from the findings of the other skills (market-research, competitor-intel, opportunity-finder). If those have not run, gather the evidence first.

## Structure

Use these sections in this order. Omit a section only if the user explicitly excludes it, and say that you did.

1. Executive summary (one page: the question, the answer, three to five key figures, the main recommendation)
2. Research objectives and scope
3. Market overview
4. Market size and growth (TAM / SAM / SOM with methodology)
5. Market segmentation
6. Competitor landscape
7. Customer insights
8. Product analysis and gaps
9. Industry trends
10. Pricing intelligence
11. SWOT analysis
12. Opportunities and threats
13. Market entry recommendations
14. Strategic recommendations
15. Sources and citations
16. Research methodology
17. Data limitations
18. Confidence assessment (overall rating plus a rating per major finding)

## Writing rules

- Lead each section with its conclusion, then the evidence.
- Every quantitative claim carries a source link and date, or the label "estimate" with its formula.
- Use tables for comparisons and prose for reasoning. Avoid bullet lists of unsupported claims.
- Keep quotations under fifteen words, and at most one per source. Paraphrase everything else.
- Write the confidence assessment honestly. A report with several "low confidence" findings is more useful than one that hides them.

## Delivery

- For a short document the user will read once, answer in the chat.
- For a report the user will keep, edit, or share, create it as a doc (use the docs skill if available) or a Word file if the user names .docx. Include the table of contents and the sources list at the end.
- Offer a one-line next step: which section needs more evidence, or which assumption to test first.
